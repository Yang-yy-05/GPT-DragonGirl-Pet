# GPT 小龙桌宠

一只住在 Windows 桌面上的白发小龙娘：应用台词、点击互动、小黄鸭音效、专注番茄钟、Codex 额度提醒，以及早晚和节日彩蛋。使用 C# / WPF 独立实现，参考 [DeepSeek Balance Whale Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) 的拖拽吸附、按压弹性、台词气泡等交互。

## 下载即用

前往 [Releases](https://github.com/Yang-yy-05/GPT-DragonGirl-Pet/releases/latest)，下载 **GPT-DragonGirl-Pet-v1.2.0-win-x64.zip**。这是自带 .NET 运行环境的 Windows 10/11 x64 分享版，无需安装 Python、Node.js、.NET 或开发工具。

1. 将整个 ZIP 解压到有写入权限的文件夹，例如桌面或个人应用目录。
2. 双击文件夹内的 `GPTPet.exe`，不要直接在压缩包内运行或只复制 exe。
3. 点击小龙脚下的「设置」调整字体、音量、置顶、专注与提醒；可在设置里创建当前电脑的桌面快捷方式。

桌宠、表情、点击音效、番茄钟和时间彩蛋均可离线使用。**额度查询需要使用者自己安装并登录 Codex**，只显示其本人的订阅额度；未安装 Codex 时，其他功能仍然可用，也可关闭额度查询和提醒。发行包不含开发者的账号、个人设置、使用记录或固定路径快捷方式。

当前发行包适用于 x64 Windows；不支持 macOS / Linux，ARM64 尚未单独构建验证。程序未做商业代码签名。

## 运行

分享版直接运行解压目录中的 `GPTPet.exe`。从源码执行 `build.ps1` 构建的是体积较小的本地版本，需要 .NET 10 Desktop Runtime，之后使用根目录 `启动桌宠.cmd` 或 `发布/GPT小龙/GPTPet.exe` 启动。不要单独移动 exe；旁边的图片、配置及 dll 都需要保留。快捷方式需在使用者自己的电脑上生成。

首次运行会显示桌宠。右键桌宠或托盘图标打开菜单；桌宠脚下的「小龙 · 设置」可以打开完整设置。

## v1.2：专注陪伴、额度提醒与时间彩蛋

- **专注陪伴**：设置新增独立页面和开关，默认 25 分钟专注 / 5 分钟休息，可改为 1–180 / 1–60 分钟。手动开始后小龙读书，脚下显示倒计时；支持暂停、继续、结束。专注期间暂停自动应用台词和时间问候，点击互动和额度提醒仍可用。到点自动进入休息，下一轮手动开始。更改时长从下一阶段生效。正常退出保存并暂停计时，重新启动可继续；关闭功能会结束本轮。电脑睡眠期间时间继续流逝，恢复后最多推进一个阶段，休息从恢复时开始，不补跑多轮。
- **额度提醒**：在「额度与提醒」开启 / 关闭，默认剩余 ≤ 20%，阈值可设 1–99%。需同时开启额度查询，启用后每 3 分钟后台查询，短周期 / 周窗口分别判断。同一次低额度状态只提醒一次，本地保存去重记录，重启不刷屏。可独立关闭额度回升提醒；回升必须由新的官方查询确认，不会因为重置倒计时结束就宣称额度恢复。隐藏、关闭气泡或全屏静默时不弹提示，恢复后仅依据仍然新鲜的数据判断。
- **时间彩蛋**：提供总开关，以及早安、深夜、节日三个独立开关。按电脑本地时间，06:00–11:00 揉眼睛问早，23:00–次日 05:00 打哈欠提醒休息；同一早晨 / 同一夜晚各一次，跨午夜及重启不重复。错过时段不补发。专注或静默时推迟问候。
- **节日装扮**：元旦当天、农历正月初一到初七穿新年灯笼装，12 月 24–26 日穿圣诞礼物装。节日期间待机穿新衣，互动结束后恢复；每个节日问候一次。新生成的四张透明 PNG 位于 `图片/时间彩蛋/`，使用内置 image_gen，提示词和参考图角色记录在 `prompts.json`。可在「时间彩蛋」和「表情收藏」随时预览，预览不消耗当天问候。

## 启动、声音与思考气泡

- **开机自启动**：位于「陪伴与互动 → 启动与窗口」，默认关闭。开启后在当前用户的 Windows 启动文件夹创建小龙自己的快捷方式，下次登录后自动启动；关闭时只移除这个快捷方式。开关以实际启动项为准，不只记录一个布尔值。如果在 Windows 任务管理器中禁用了该启动项，Windows 的禁用设置优先。移动程序目录后，在新位置重新打开此开关和更新桌面快捷方式。
- **始终置顶**：设置首屏、右键菜单、托盘菜单均可自由开启 / 关闭，立即生效并保存，三个入口同步。全屏隐身为独立设置，如果希望在全屏窗口上也显示小龙，关闭「全屏时自动隐身」。置顶不抢键盘焦点；Windows 安全桌面或独占全屏由系统控制。
- **小黄鸭点击音效**：鼠标按下桌宠时立即播放用户提供视频中的原音，无需等待松开；启动和调整音量时预先加载。截取视频 0.468–0.94 秒的一声完整音效，去掉前导空白，保留原采样率、音色和速度。音频随程序打包在 `assets/rubber-duck.wav`，不需要原视频或网络；应用切换不发声，拖动只在最初按下时响一声。设置中可关闭、调音量（0–100）或试听；默认音量 55%。连续点击复用单声道播放，避免多路音效叠加。
- **思考气泡**：平滑椭圆和两颗思考小圆点，搭配柔和紫色。设置中的「气泡与字体」可选择内置站酷快乐体或本机字体，正文字号可在 12–28 之间按 0.5 调整；标题和说明文字按比例缩放。内置字体无需安装，无法找到所选字体时回退内置字体。修改立即生效并自动保存，提供日常台词 / 额度排版实时预览、桌宠预览和恢复默认按钮。短句居中，多行信息左对齐；气泡随内容调整宽高，较长消息可以滚动查看，点击气泡关闭。
- **小龙图标**：复用已有角色制作 16 / 24 / 32 / 48 / 64 / 128 / 256 像素的 Windows ICO，用于 exe、托盘和快捷方式。资源位于 `assets/gpt-dragon.ico`，预览为 `assets/gpt-dragon.png`。设置中可创建或更新桌面快捷方式。

## 应用识别

每 450 毫秒读取前台窗口的进程名和标题，稳定约 0.8 秒后匹配规则。后台应用不会触发；浏览器页面需要切到对应标签页，且标题包含关键词。对改了标题、纯视频全屏、隐藏应用名的标签，可自行添加关键词。

同一应用连续停留不重复提示。切出再切回也受冷却限制（默认 90 秒，可调）。未知应用不弹窗。应用识别、动态效果、气泡、置顶、全屏隐身均可分别关闭。隐藏在托盘期间停止应用反馈。

预设 22 条规则，涵盖 DeepSeek Harness（「好模型」）、B 站（「你所热爱的就是你的生活」）、ChatGPT、Codex、DeepSeek、Steam、Epic、VS Code、Cursor、IDE、GitHub、网易云、QQ 音乐、Spotify、微信、QQ、抖音、知乎、Office、OBS、Blender、Minecraft、原神 / 星穹铁道、终端等。

在「应用与台词」选择规则，修改进程名、标题关键词、台词和表情后保存。多个候选以 `|` 分隔。进程名精确匹配（大小写不敏感，允许 `.exe`），标题按字面包含匹配，不执行正则或代码。独立应用优先看进程名，避免编辑器打开 `ChatGPT.md` 时误报；浏览器、终端等宿主优先看标题，以识别网站或 DSH。相同匹配层级按规则顺序优先，Harness 放在 DeepSeek 前面。可以添加、禁用、移除规则，测试匹配或直接预览反馈。规则编辑中的改动需要点击保存。

## 额度

通过本机官方 Codex App Server 的 `account/rateLimits/read` 查询，不解析浏览器 cookie，不要求粘贴密钥，不发起模型对话，也不购买额度、不消耗额度重置机会。服务复用 Codex 已有登录；需要能正常运行并登录的 Codex。设置里可指定 `codex.exe` 路径。连接使用标准输入输出，子进程隐藏启动，查询完成后结束。

采用 `rateLimitsByLimitId` 多桶数据，缺省回退 `rateLimits`；剩余百分比为 `100 - usedPercent`。窗口长度与重置时间均按接口返回值显示，不假定永远是 5 小时 / 1 周。每 3 分钟最多自动查询一次，开启额度提醒后后台轮询；关闭提醒时仅在额度相关应用活跃时触发，也可手动刷新。

**这里显示的是 Codex 订阅额度。** 按用户指定，打开 ChatGPT 或 Codex 均展示 Codex 订阅的短周期 / 周窗口，并明确标注来源；不把这些数字当成网页聊天剩余次数。

未取得数据时显示「暂不可用」，不显示伪造数字。失败后保留上一份结果并标「待刷新」；超过 5 分钟的数据标记过期；已过重置时间的窗口显示「等待刷新」，不会擅自归零或恢复 100%。后台缓存更新仅在达到提醒条件时弹出气泡，打开相关应用或点击刷新也可看到新值。

官方协议来源：[Codex App Server](https://learn.chatgpt.com/docs/app-server)。

## 本地数据与隐私

`GPTPet.exe` 同目录下的 `data/settings.json` 保存窗口位置和设置；`data/rules.json` 保存自定义规则。默认规则位于 `config/default-rules.json`。不记录前台窗口标题或应用历史，不上传窗口信息。额度查询只由官方 Codex 进程连接其官方服务。不会读取聊天正文。关闭额度查询后不再启动新查询（已经发出的查询会结束）。退出可从右键 / 托盘菜单操作。

`data/companion.json` 保存专注阶段、累计完成轮数、额度提醒去重状态和最近问候日期，均仅保存在本机。

配置写入采用临时文件再替换。损坏 JSON 保留 `.invalid-*` 备份并回退默认值。启动位置会限制在当前屏幕工作区，防止拆掉显示器后找不到桌宠。

## 开发与验证

安装 .NET 10 SDK 后运行 `./build.ps1` 构建本地版本。应用代码无第三方 NuGet 依赖。

执行 `./package.ps1` 构建分享版：从微软 NuGet 下载 Windows x64 运行时，执行自检，在全新的暂存目录排除运行数据和调试文件，然后生成 ZIP 和 SHA-256 校验文件。产物位于 `artifacts/`，不会覆盖正在使用的 `发布/GPT小龙/`。每次打包会使用独立目录，不会把已有设置混入发布包。

`GPTPet.exe --self-test` 执行规则匹配、去抖、冷却、额度解析、缓存过期、窗口位置、图片透明度、配置恢复等测试，结果写入程序旁 `test-results.txt`，退出码 0 表示通过。

`GPTPet.exe --quota-check` 执行一次真实额度查询，只把规范化后的窗口、百分比、时间与错误状态写入 `data/quota-check.json`，不保存凭据或原始账号响应。`GPTPet.exe --settings` 启动时直接打开设置。
